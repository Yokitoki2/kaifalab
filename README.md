# Сайты доставки еды (по городам)

Хостинг: **GitHub Pages**. DNS: **Cloudflare (только DNS, серое облако)**.
Один город = один репозиторий = один домен.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Страница (заменить на заказной дизайн) |
| `style.css` | Стили |
| `config.js` | **Ссылки и названия по доменам — редактировать здесь** |
| `app.js` | Логика подстановки ссылок (не трогать) |
| `logo.svg`, `favicon.svg` | Логотип и иконка вкладки |
| `CNAME` | Домен этого репозитория (одна строка, например `kaif-food.ru`) |
| `robots.txt` | Для поисковиков |

## Новый город
1. Создать новый публичный репозиторий и загрузить в него все файлы.
2. В файле `CNAME` указать домен города.
3. В `config.js` добавить строку с доменом и ссылками (можно держать одинаковый `config.js` во всех репозиториях).

## Как поменять ссылки
Репозиторий города → `config.js` → карандаш (Edit) → поменять ссылки → **Commit changes**.
Через 1–2 минуты сайт обновится. Порядок ссылок: `[бот, меню, помощь]`.

## Требования к новому дизайну
1. У кнопок должны остаться `id="0"` (бот), `id="1"` (меню), `id="2"` (помощь).
2. Внизу страницы оставить `<script src="config.js">` и `<script src="app.js">` (в таком порядке).
3. Элементы с названием города помечать атрибутом `data-site-name`.

В `index.html` есть строка `Content-Security-Policy`. Если дизайн подключает Google Fonts,
внешние скрипты или картинки с других сайтов — добавьте их домены в эту строку, иначе они заблокируются.
Встроенные `<script>…</script>` и `style="…"` она тоже блокирует.
